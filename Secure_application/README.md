# Secure Application - Password Manager

## 1. Project Overview

This project implements a simple Password Manager in Python.

The application stores:

* Username
* Website name
* Password

The purpose of this project is to demonstrate basic application security concepts and Static Application Security Testing (SAST).

The application is intentionally vulnerable for educational purposes.

**This application must not be used to store real passwords or sensitive information.**

---

## 2. Technologies Used

* Python 3
* SQLite
* Bandit SAST
* Linux Terminal
* Git/GitHub

---

## 3. Application Features

The Password Manager provides the following functions:

1. Add a password
2. View stored passwords
3. Search for a password using the website name
4. Exit the application

---

## 4. Intentional Vulnerabilities

The application contains the following vulnerabilities for demonstration:

### Missing Authentication

There is no login or authentication mechanism. Anyone who can run the application can access the stored credentials.

### Information Leakage

The application displays passwords directly in the terminal when credentials are viewed or searched.

### Insecure Storage

Passwords are stored as plaintext in the SQLite database without encryption or cryptographic protection.

Cryptographic protection is intentionally not implemented because cryptography is introduced later in the assignment.

* Bandit

```bash
python3 --version
```

Check Bandit:

```bash
bandit --version
```

Check SQLite:

```bash
sqlite3 --version
```

---

## 7. Running the Application

Navigate to the source directory:

```bash
cd src
```

Run the application:

```bash
python3 password_manager.py
```

The application provides a menu for adding, viewing, and searching stored credentials.

---

## 8. Running SAST with Bandit

From the `Secure_application` directory, run:

```bash
bandit -r src/
```

To save the Bandit results as a text report:

```bash
bandit -r src/ -f txt -o sast/bandit_report.txt
```

The generated report is stored in:

```text
sast/bandit_report.txt
```

---

## 10. Security Limitations

This application is intentionally insecure and is developed only for educational purposes.

It does not currently provide:

* User authentication
* Password encryption
* Secure secret management
* Access control
* Secure password display

These security mechanisms can be introduced in later stages of the project.

---

## 11. Conclusion

This project demonstrates how security vulnerabilities can be introduced into a simple application and how SAST tools such as Bandit can be used to analyze source code for security issues.

The project also demonstrates that automated SAST tools do not necessarily detect every application-level vulnerability. Therefore, SAST results are complemented with manual testing and code review.
